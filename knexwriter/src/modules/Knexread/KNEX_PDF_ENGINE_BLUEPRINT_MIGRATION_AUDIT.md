# Auditoria do knex-pdf-engine para migracao Blueprint

Data: 2026-06-01

Objetivo: separar o motor de leitura/extracao do legado de apresentacao raster/canvas antes de qualquer remocao.

## Resumo por categoria
- Essencial para leitura/extracao: 48 arquivo(s)
- Essencial para novo blueprint: 4 arquivo(s)
- Fallback temporario: 8 arquivo(s)
- Legado de apresentacao raster/canvas: 19 arquivo(s)

## Decisoes gerais
- O modo blueprint deve ser o caminho padrao de apresentacao reconstruida apos validacao em navegador.
- Arquivos de tile/canvas integral entram em legacy/fallback, nao em apresentacao principal.
- Backends e extracao devem ser preservados, mas a apresentacao deve migrar para rendering/blueprint e rendering/composition.
- Nenhum arquivo foi removido nesta fase.
