# Plano de testes iniciais (fundação DB)

- Criar projeto.
- Criar documento.
- Adicionar `FileAsset`.
- Vincular `ProjectFile` ao projeto/documento.
- Criar `ReferenceSource`.
- Criar `ReferenceAuthor`.
- Vincular `ReferenceAttachment` ao `FileAsset`.
- Criar `CitationOccurrence`.
- Criar `CitationLocator`.
- Criar `DocumentCitationLink`.
- Regenerar bibliografia por documento.
- Remover citação e confirmar saída da bibliografia.
- Marcar `includeAsConsultedWork` e manter entrada na bibliografia.
- Criar `PdfAnnotation`.
- Vincular `PdfAnnotation` a `CitationOccurrence`.
- Indexar e buscar texto em `FileTextIndex`.
- Detectar duplicidade de fonte por DOI/ISBN.
